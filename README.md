# Creative Animation Project 🎨✨

A visually engaging and creative animation project built using only **HTML** and **CSS**. This project showcases modern animations and interactive effects without using JavaScript.

---

## 🚀 Features

- Smooth and creative animations
- Pure HTML & CSS implementation
- Responsive design
- Modern UI effects
- Beginner-friendly code structure
- Clean and attractive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## 📌 Project Overview

This project was created to explore the creativity of web design using only frontend basics. It demonstrates how beautiful animations and engaging visual effects can be built using CSS animations, transitions, and keyframes.

---

## 🌟 What I Learned

- CSS animations and keyframes
- Transform and transition effects
- Responsive web design
- Creative styling techniques
- Building interactive UI without JavaScript
